# java-kanban
Repository for homework project.

## Описание
Backend трекера задач для управления задачами, эпиками и подзадачами.

## Функциональность
- Создание, обновление и удаление задач трех типов
- Автоматический расчет статуса эпика на основе подзадач
- Управление связями между эпиками и подзадачами
- Уникальная идентификация всех задач по ID
- История просмотров (неограниченный размер, без дубликатов)
- Автоматическое сохранение состояния менеджера в файл
- Восстановление состояния менеджера из файла
- Интерфейсная архитектура для гибкости реализации
- Две реализации менеджера: с хранением в памяти и с автосохранением в файл

## Классы задач

### Task - Базовый класс задачи
Хранит основные свойства задачи: id, название, описание, статус, продолжительность и время старта.

**Конструкторы:**
- `Task(String title, String description, TaskStatus status)` – создаёт задачу с duration = 0 и startTime = null.
- `Task(String title, String description, TaskStatus status, Duration duration, LocalDateTime startTime)` – 
создаёт задачу с заданной продолжительностью и временем старта.

**Методы:**
- `getDuration()` / `setDuration(Duration)` – продолжительность задачи.
- `getStartTime()` / `setStartTime(LocalDateTime)` – время начала.
- `getEndTime()` – рассчитывает время завершения как `startTime + duration` 
(может вернуть null, если startTime или duration не заданы).

### Epic - Класс эпика
Наследуется от Task. Представляет сложную задачу, состоящую из подзадач.

**Дополнительные свойства:**
- `subtaskIds` - список ID подзадач.
- `endTime` - расчётное время завершения эпика (самое позднее из подзадач).

**Особенности:** Статус эпика, его продолжительность, startTime и endTime рассчитываются автоматически менеджером 
на основе подзадач через методы `updateEpicStatus()` и `updateEpicTime()` в `InMemoryTaskManager`.

### Subtask - Класс подзадачи
Наследуется от Task. Представляет задачу, относящуюся к эпику.

**Дополнительные свойства:**
- `epicId` - ID родительского эпика.

**Конструкторы:**
- `Subtask(..., int epicId)` – без времени.
- `Subtask(..., int epicId, Duration duration, LocalDateTime startTime)` – с продолжительностью и временем старта.

## Менеджер задач

### TaskManager - Интерфейс менеджера задач
Определяет контракт для управления задачами всех типов.

**Метод:**
- `List<Task> getPrioritizedTasks()` – возвращает список всех задач и подзадач, отсортированный по `startTime` 
(задачи с `null startTime` помещаются в конец). 
Сложность получения – O(1) (используется предварительно отсортированная структура).

### InMemoryTaskManager - Реализация менеджера задач
Централизованное управление всеми типами задач с хранением в оперативной памяти.

#### Хранение данных
- Три HashMap для раздельного хранения задач.
- Уникальная генерация ID через счетчик.
- Быстрый доступ O(1) по идентификатору.
- `TreeSet<Task> prioritizedTasks` – отсортированное множество для задач и подзадач по `startTime` 
(компаратор с `nullsLast`).

#### Основные методы
- `getPrioritizedTasks()` – возвращает копию `prioritizedTasks` (O(1) по времени получения).
- При создании/обновлении задачи или подзадачи выполняется проверка на пересечение временных интервалов 
с уже существующими задачами (исключая саму себя). Если пересечение найдено – выбрасывается `ManagerSaveException`.
- При изменении подзадач эпика автоматически пересчитываются его статус, продолжительность, `startTime` и `endTime` 
через вызов `updateEpicParameters()` → `updateEpicStatus()` и `updateEpicTime()`.

### Расчет статуса эпика
Статус автоматически пересчитывается при изменении подзадач:

1. Нет подзадач → NEW
2. Все подзадачи NEW → NEW
3. Все подзадачи DONE → DONE
4. Остальные случаи → IN_PROGRESS

**Расчёт времени эпика:**
- Продолжительность = сумма продолжительностей всех подзадач.
- `startTime` = самая ранняя дата начала среди подзадач (или null, если нет подзадач с заданным временем).
- `endTime` = самая поздняя дата завершения среди подзадач (или null).

## История просмотров

### HistoryManager - Интерфейс менеджера истории
Определяет контракт для управления историей просмотров задач.

### InMemoryHistoryManager - Реализация менеджера истории
Хранит историю просмотренных задач с использованием собственного двусвязного списка и HashMap.

#### Особенности работы истории:
- Добавляет задачу в историю при вызове getTask(), getEpic(), getSubtask()
- **Не допускает дублирование задач в истории** (предыдущий просмотр удаляется)
- Возвращает задачи в порядке их просмотра
- **Не ограничена по размеру** (хранит всю историю просмотров)

#### Структура данных:
- Собственный двусвязный список для хранения порядка просмотров
- HashMap для быстрого доступа к узлам списка по ID задачи
- Время выполнения всех операций - O(1)

#### Основные методы:
- `add(Task task)` - помечает задачу как просмотренную (удаляя предыдущий просмотр)
- `getHistory()` - возвращает список просмотренных задач
- `remove(int id)` - удаляет задачу из истории по ID
- `clear()` - полностью очищает историю просмотров

## FileBackedTaskManager - Реализация менеджера с автосохранением
Наследует InMemoryTaskManager и добавляет функциональность автоматического сохранения состояния в файл.

#### Особенности реализации:
- Автоматическое сохранение после каждой модифицирующей операции
- Сохранение данных в текстовом формате CSV с заголовком: `id,type,name,status,description,epic,duration,startTime`
- Поддержка полей `duration` (в минутах) и `startTime` (строка ISO)
- Экранирование запятых в названии и описании (`\,`).
- Возможность восстановления состояния менеджера из файла (с пересчётом статусов и времени эпиков)
- Использование полиморфного метода `getType()`

## Утилитарный класс

### Managers - Фабричный класс
Предоставляет методы для получения экземпляров менеджеров.

#### Методы:
- `getDefault()` - возвращает реализацию TaskManager (InMemoryTaskManager)
- `getDefaultHistory()` - возвращает реализацию HistoryManager (InMemoryHistoryManager)

## TaskStatus - Перечисление статусов
Тип данных `enum`:

- `NEW` - задача создана
- `IN_PROGRESS` - задача выполняется
- `DONE` - задача завершена

## TaskType - Перечисление типов задач
Используется для сериализации/десериализации в CSV:

- `TASK` - обычная задача
- `EPIC` - эпик
- `SUBTASK` - подзадача

## Особенности реализации
- Наследование Epic и Subtask от Task
- Интерфейсная архитектура для гибкости реализации
- Инкапсуляция полей с доступом через геттеры/сеттеры
- Проверки целостности данных и обработка ошибок
- Эффективное хранение в HashMap с быстрым доступом по ID
- Собственная реализация двусвязного списка для истории просмотров
- Две реализации менеджера:
    - InMemoryTaskManager - хранение данных в оперативной памяти
    - FileBackedTaskManager - автоматическое сохранение в файл (CSV формат)
- Сериализация/десериализация задач в CSV формат
- Кастомное исключение ManagerSaveException для обработки ошибок файловой системы
- Поддержка продолжительности и времени старта для задач и подзадач
- Автоматическая сортировка задач по приоритету (времени начала) через TreeSet
- Проверка пересечения временных интервалов при добавлении/обновлении задач (выбрасывается ManagerSaveException)
- Расчёт времени эпика (продолжительность, startTime, endTime) на основе подзадач в менеджере через 
метод `updateEpicTime()`

## HTTP API

### HttpTaskServer - HTTP сервер для доступа к TaskManager

Предоставляет REST API для взаимодействия с менеджером задач через HTTP запросы. Сервер запускается на порту 8080.

#### Эндпоинты

| HTTP метод | URL                  | Описание                                            | Статусы ответа |
|:-----------|:---------------------|:----------------------------------------------------|:---------------|
| GET        | /tasks               | Получить все задачи                                 | 200            |
| GET        | /tasks/{id}          | Получить задачу по ID                               | 200, 404       |
| POST       | /tasks               | Создать или обновить задачу                         | 201, 406       |
| DELETE     | /tasks/{id}          | Удалить задачу по ID                                | 200            |
| DELETE     | /tasks               | Удалить все задачи                                  | 200            |
| GET        | /subtasks            | Получить все подзадачи                              | 200            |
| GET        | /subtasks/{id}       | Получить подзадачу по ID                            | 200, 404       |
| POST       | /subtasks            | Создать или обновить подзадачу                      | 201, 404, 406  |
| DELETE     | /subtasks/{id}       | Удалить подзадачу по ID                             | 200            |
| DELETE     | /subtasks            | Удалить все подзадачи                               | 200            |
| GET        | /epics               | Получить все эпики                                  | 200            |
| GET        | /epics/{id}          | Получить эпик по ID                                 | 200, 404       |
| GET        | /epics/{id}/subtasks | Получить подзадачи эпика                            | 200, 404       |
| POST       | /epics               | Создать или обновить эпик                           | 201            |
| DELETE     | /epics/{id}          | Удалить эпик по ID                                  | 200            |
| DELETE     | /epics               | Удалить все эпики                                   | 200            |
| GET        | /history             | Получить историю просмотров                         | 200            |
| GET        | /prioritized         | Получить задачи в порядке приоритета (по startTime) | 200            |

#### Коды ответа

| Код                       | Описание                                       |
|:--------------------------|:-----------------------------------------------|
| 200 OK                    | Успешный ответ с данными                       |
| 201 Created               | Ресурс успешно создан                          |
| 404 Not Found             | Ресурс не найден                               |
| 406 Not Acceptable        | Задача пересекается по времени с существующими |
| 500 Internal Server Error | Внутренняя ошибка сервера                      |

## Тестирование
Проект покрыт юнит-тестами с использованием JUnit:

**Базовые тесты:**
- Проверка равенства задач с одинаковым ID
- Проверка невозможности добавления эпика в качестве подзадачи к самому себе
- Проверка автоматического расчета статуса эпика
- Проверка неизменности задачи при добавлении в менеджер
- Проверка работы утилитарного класса

**Тесты истории просмотров:**
- Проверка неограниченного размера истории
- Проверка отсутствия дубликатов в истории
- Проверка удаления задачи из истории по ID
- Проверка удаления из начала, середины и конца списка
- Проверка корректного порядка просмотра задач
- Проверка очистки всей истории
- Проверка удаления эпика вместе со всеми подзадачами из истории

**Тесты файлового менеджера:**
- Проверка сохранения и загрузки пустого файла
- Проверка сохранения и загрузки нескольких задач разных типов
- Проверка сохранения и загрузки эпика с несколькими подзадачами
- Проверка обработки исключения при чтении несуществующего файла
- Проверка модификации задач после восстановления из файла
- Проверка сохранения и загрузки задач с duration и startTime
- Проверка пересчёта времени эпика после загрузки из файла
- Использование временных файлов (File.createTempFile) для изоляции тестов

**Тесты приоритетов, пересечений и времени эпика:**
- Проверка сортировки задач по startTime в getPrioritizedTasks()
- Проверка, что задачи с null startTime не попадают в приоритетный список
- Проверка, что подзадачи также учитываются в приоритетном списке
- Проверка запрета на создание пересекающихся задач (ManagerSaveException)
- Проверка запрета на создание подзадачи, пересекающейся с существующей задачей
- Проверка, что непересекающиеся задачи добавляются без ошибок
- Проверка всех граничных условий статуса эпика (все NEW, все DONE, смешанные, IN_PROGRESS)
- Проверка корректного расчёта продолжительности, startTime и endTime эпика на основе подзадач
- Проверка, что у эпика без подзадач duration = 0, startTime/endTime = null

**Тесты HTTP API:**
- Проверка создания, получения, обновления и удаления задач через HTTP
- Проверка создания, получения и удаления эпиков через HTTP
- Проверка создания, получения и удаления подзадач через HTTP
- Проверка получения истории просмотров через HTTP
- Проверка получения приоритетных задач через HTTP
- Проверка статусов ответов (200, 201, 404, 406, 500)

Абстрактный базовый класс `AbstractTaskManagerTest` позволяет переиспользовать все общие тесты для 
`InMemoryTaskManager` и `FileBackedTaskManager`.
